Turbulent Boundary-Layer Theory

01Friction Velocity

  • Freestream을 기준으로 유동을 해석할 때는 \(U_{\infty}\)를 Reference Velocity로 사용할 수 있음. 반면 Boundary-Layer Edge의 국소 속도는 \(U_e(x)\)로 구분함.
  • 하지만 벽에 매우 가까운 유체 요소를 생각해보면, boundary layer 바깥의 자유류 속도 보다 벽면의 shear stress의 영양을 더 많이 받음
  • 따라서 벽 근처의 유동 현상을 정량적로 묘사하려면 자유류 속도 \(U_{\infty}\) 대신 벽면 마찰의 크기를 대변하는 벽면 전단응력 에 기반한 새로운 기준 속도(Reference Scale)가 필요
  • 이를 Friction Velocity 로 정의하며 다음과 같음
  • \(\tau_w/\rho\)는 속도 제곱의 차원을 가지므로, Friction Velocity \(u_\tau\)를 다음과 같이 정의
    \[u_\tau=\sqrt{\frac{|\tau_w|}{\rho}}.\]
    \[\left[\frac{\tau_w}{\rho}\right] =\frac{\mathrm{N/m^2}}{\mathrm{kg/m^3}} =\mathrm{m^2/s^2}.\]
  • \(u_\tau\)는 실제 유체 입자의 이동 속도가 아니라, 벽면 전단응력의 크기를 속도 단위로 표현한 Scale임. 이하의 벽면 속도분포 유도에서는 \(\tau_w>0\)인 부착유동을 고려함.

02Viscous Length Scale

  • 위의 설명과 같이 벽 근처유동은 자유류 유동과 다른 특성을 가지며 같은 실제 거리 \(y\)만큼 떨어져 있어도 유체의 점성이나 벽면 마찰이 다르면 난류 구조가 달라짐
  • 따라서 \(u_\tau\)와 함께 사용할 벽면 기준의 길이 규모가 필요하며 이를 Viscous Length Scale로 아래와 같이 정의
    \[\ell_\nu=\frac{\nu}{u_\tau}.\]
    \[[\ell_\nu] =\left[\frac{\nu}{u_\tau}\right] =\frac{\mathrm{m^2/s}}{\mathrm{m/s}} =\mathrm{m}\]
  • 앞에서 정의한 Viscous Length Scale \(\ell_\nu\)의 물리적 의미를 이해하기 위해, 먼저 Dynamic Viscosity와 Kinematic Viscosity의 차이를 살펴볼 필요가 있음
    • Dynamic Viscosity (\(\mu\)) : 유체 내부에서 속도 구배에 의해 발생하는 점성 전단응력의 크기를 결정하는 물성치로, 직관적으로 유체의 끈적이는 정도를 나타냄
    • Kinematic Viscosity (\(\nu=\mu/\rho\)) : 점성 효과를 밀도, 즉 관성의 크기로 나눈 값으로, 점성에 의한 운동량 변화가 얼마나 빠르게 확산되는지를 나타냄
  • 따라서 Viscous Length Scale \(\ell_\nu\)는 벽면 근처에서 점성에 의해 운동량이 확산되는 대표적인 characteristic legnth
  • Viscous Length Scale의 크기는 다음과 같은 물리적 의미를 가짐
    • High \(\ell_\nu\) : 점성에 의한 운동량 확산이 상대적으로 강해, 속도가 변화하는 거리 스케일이 커짐.
    • Low \(\ell_\nu\) : 벽면 전단응력에 따른 속도 변화가 상대적으로 강해, 짧은 거리에서 속도가 급격하게 변함.

03Dimensionless Wall Coordinates

  • 벽면으로부터의 실제 거리 \(y\)가 같더라도 유동 조건에 따라 벽 근처에서의 물리현상은는 달라질 수 있음
  • 예를 들어 같은 \(y=1mm\) 이라도 어떤 유동에서는 아직 점성의 영향이 지배적일 수도 있지만, 다른 유동에서는 이미 점성 영향이 약해진 거리일 수도 있음
  • 따라서 벽 근처 유동에서는 실제 거리 \(y\) 를 그대로 사용하지 않고, viscous length scale \(\ell_\nu\) 로 나누어 무차원 거리로 표현하며 이를 Dimensionless wall distance \(y^+\) 라 함
  • 실제 거리 \(y\)와 평균속도 \(\overline{U}\)는 유동 조건마다 크기가 다르므로, 서로 다른 벽면 유동을 비교하기 위해 \(\ell_\nu\)와 \(u_\tau\)로 무차원화함.
    \[y^+=\frac{y}{\ell_\nu}=\frac{yu_\tau}{\nu}\]
  • \(y^+\)는 벽면으로부터 몇 개의 Viscous Length 만큼 떨어져 있는지를, 예를 들어 \(y^+=3\)이면 \(y=3\ell_\nu\)
  • 평균속도 \(\overline{U}\) 또한 위처럼 유동조건에 따라 벽 근처에서의 물리적 의미가 달라질수 있음
  • 같은 \(\overline{U}=10 m/s\) 라도 느린 저속 유동의 경우처럼 이미 자유류 속도에 도달한 매우 빠른 속도일 수도 있지만, 엄청난 고속 유동에서는 이제 막 벽면 마찰을 벗어나기 시작한 아주 느린 속도 일 수 있음
  • 따라서 속도 또한 Dimensionless velocity 로 다음과 같이 정의
    \[u^+=\frac{\overline{U}}{u_\tau}.\]
  • \(u^+\)는 평균속도가 Friction Velocity 의 몇 배인가를 나타냄.
  • \(y^+\) 랑 \(y/\delta\) 두 변수를 기준으로 layer들을 나눴는데 이 두 변수는 다음과같이 연결 가능
    \[\begin{aligned} y^+ &=\frac{yu_\tau}{\nu},\\[2.0em] &=\frac{y}{\delta}\frac{\delta u_\tau}{\nu},\\[2.0em] &=Re_\tau\frac{y}{\delta}, \qquad \left( \because\ Re_\tau=\frac{\delta u_\tau}{\nu} \right) . \end{aligned}\]
  • 즉, \(y^+\)와 \(y/\delta\)는 서로 다른 영역을 뜻하는 기호가 아니라 같은 거리를 다른 기준 길이로 나타낸 좌표임. 두 길이 규모의 차이를 이해하면 Inner, Outer 및 Overlap Region의 관계를 설명할 수 있음.
  • 이때, \(Re_\tau\)는 Friction Reynolds Number로, 전체 경계층 두께 \(\delta\)가 Viscous Length scale \(\ell_\nu\)의 몇 배인지를 나타냄
    \[Re_\tau=\frac{\delta u_\tau}{\nu} =\frac{\delta}{\ell_\nu}\]
  • 각 무차원수의 물리적 의미는 다음과 같이 정리 가능
    • \(y^+=\dfrac{y}{\ell_\nu}\) : 벽면으로부터 몇 개의 Viscous Length Scale만큼 떨어져 있는지
    • \(\dfrac{y}{\delta}\) : 벽면으로부터 전체 경계층 두께의 몇 배만큼 떨어져 있는지
    • \(Re_\tau=\dfrac{\delta}{\ell_\nu}\) : 전체 경계층 두께가 viscous length scale의 몇 배인지
